# Palette lock — Night Library

Chosen system for v1. Midnight paper, warm ink, copper, a little dusk teal and burgundy. Printable journal pages stay parchment, never full-bleed navy.

| Token | Hex | Use |
| --- | --- | --- |
| midnight | `#1B2433` | Cover, part bands, display rules |
| charcoal | `#2C3544` | Secondary panels |
| parchment | `#F6F1E7` | Page ground |
| ivory | `#FBF8F2` | Journal writing ground |
| ink | `#241F1C` | Body text |
| copper | `#A85A32` | Motifs, rules, index tabs |
| gold | `#C6A15B` | Small stars and folio ornaments |
| teal | `#3E6464` | Secondary motif accent |
| burgundy | `#7C3A46` | Desire and signature accents |
| line | `#D9CFC0` | Journal rules |
| pause | `#3E6464` | Pause glyph, never the only signal |

Type: Palatino Linotype for titles, Georgia for body, Calibri for metadata. No bundled fonts. Handwritten texture is a drawn SVG scribble, not a redistributed script font.

Motifs are line drawings: paired circles, keys, doors, paths, constellations, paper ephemera. Each chapter motif must depict its own premise. Alt text is required in `assets/ASSET_MANIFEST.csv`.
