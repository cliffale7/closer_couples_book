# Real-use book playtesting — reviewer kit

**Purpose:** Verify that a real person can open the actual book, find an activity quickly, understand the rules and conduct it without asking the author what they meant. This kit belongs to the owner; Cursor/agents may prepare synthetic dry-run logs but must never invent real participants or intimate answers.

## Suggested test activities

| ID | Why it is essential | What would indicate a failure |
|---|---|---|
| 001 The Stranger Across From Me | Fast emotional discovery; short + standard | unclear clock split, repeated questions, excessive writing to begin |
| 017 Four Minutes of Forever | nonverbal connection and accessible alternatives | pressure to stare, confusion about breaks, false scientific promise |
| 034 The Yes, No, Maybe Game | discreet adult boundaries/choices | sharing implied compulsory, unclear next action, 'yes' mistaken for consent |
| 043 The Newlywed Game | writing, guesses and reveals | incomplete question deck, hidden answers revealed too early, ambiguous scoring |
| 071 The Twelve-Hour Vacation | all-day planning | no usable four-hour option, maintenance responsibilities ignored, mislisted as multi-day |
| 097 The Emotional Archaeologists | deep original mechanic | one partner diagnoses the other, insufficient distinction from ordinary questioning |
| 103 The Relationship Escape Room | materials, two packets, spoilers | impossible grid, omitted common hours, facilitator answer visible |
| 104 The Two-Person Civilization | imaginative collaborative game | unclear rules, unfair card surprises, 10 rules too rigid |
| 106 The Intimacy Negotiators | meaningful shared planning | 100 points cannot balance, allocation used as entitlement |
| 108 The Secret Door | intense consent-led disclosure | refusal feels punished, unclear key language |
| S01 The Long Table | extended progression | concealed final prompt shown too early, session timing impractical |
| S03 The Case of the Missing Tuesday | complex deduction | player sees answer key by turning page, unsolvable plot details |
| S04 The Branching Evening | branching story-like play | branches terminate accidentally, unclear state handoff |

## Complete the same observation sheet per test

**Session metadata only (no private answers):** ID ______; variant ______; date ______; number of participants ______; medium (PDF/DOCX/EPUB/printed) ______; expected minutes ______; actual minutes ______; reviewer initials if desired ______.

**Playability checks:**
- Were the activity and its correct length found in under 60 seconds from the chosen index?
- Were setup/materials, roles, start conditions, pause/skip rules, next turns and ending immediately clear?
- Did all promised cards/grids/sheets exist in the packet? Did you need to improvise something missing?
- Were any instructions contradictory or impossible? Which exact sentence/page/step?
- Was any puzzle solution revealed prematurely, or any mandatory instruction hidden?
- Could both participants contribute fairly, with no pressure to reveal private material?
- Did the experience feel **different** from the neighboring or similar chapter?
- Could both people easily record a private page, a shared page and a repeat visit afterwards?
- Was the promised emotional or playful purpose credible without feeling forced?
- Did the session run at a believable duration for the chosen variant?

**Observed friction:** First point where someone stopped/confused ______; page/step ______; reason ______; exact suggested wording ______; missing piece ______.

**Would we repeat it?** Yes / Maybe / No / Passed (not a rating of the relationship). Why (optional) ______.

**Result:** PASS / NEEDS REVISION / SKIPPED / INCOMPLETE. Who genuinely completed this test ______. No agent may pre-fill a participant's reaction.

## Non-intimate publication checks

Ask one reader to find a 10-minute activity from the main contents; one to find S02 by mood; one to print and write in a journal page using a pen; one to start a second visit of ID 043; one to find a previous date in the chronology; and one to open the EPUB and resize text. Save usability feedback only, never relationship disclosures.

## Field-test treatment during Phase 3

Developer desk-play all 114. Prepare all 13 scripts, and if genuine readers are available with their consent during the session, record their feedback accurately. Otherwise mark individual real-use tests `PENDING HUMAN` in the status file. Complete all correctable engineering/editorial work rather than making human testing a reason to stop early.
