# Chronology index

```journal
template: chronology-index
line_spacing_min_in: 0.32
min_rules_per_prompt: 8
entry_lines: 2
entries_on_this_sheet: 8
on_overflow: add a sheet
sort: date when recopied
private_pages: omit unless the writer marks them indexable
```

One sitting, one entry. Copy this sheet for as many years as you keep the book. Each entry is two baselines at least 0.32 inch apart: the facts, then an optional memory line. Leave the memory line blank when you would rather not summarize. Recopy by date when a sheet becomes hard to read. A second stack sorted by activity ID is optional.

Do not index a private partner page unless the person who wrote it marks it indexable.

Fictional layout sample, not a record. Rowan and Vale are not the readers. Use it only to see the shape of a line: 3 April 2026 · 075 Our Greatest Hits · attempt 1 · kitchen table · “Burnt toast still counts.”
