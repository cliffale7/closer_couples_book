# Partner pages

```journal
template: partner-page
voices: [partner_a, partner_b]
equal_rules: true
line_spacing_min_in: 0.32
min_rules_per_prompt: 8
pages: 1 per voice at letter size with 0.85 in inner margin
on_overflow: add a sheet
default_share: private
```

Print Partner A and Partner B as a facing pair. Same paper, same margins, same type size, same number of lines. Baselines are at least 0.32 inch apart. A second role needs another copy of this page, not half the lines.

The first prompt slot is filled from `journal/PROMPT_BANK.md` for this activity. Paste Partner A’s prompt only on Partner A’s page, and Partner B’s only on Partner B’s page.
