# Session log

```journal
template: session-log
line_spacing_min_in: 0.32
min_rules_per_prompt: 8
on_overflow: add a sheet
header_on_continuation: Our Story, activity ID, date, attempt, whose page
```

Print every baseline at least 0.32 inch apart. Fact lines count as baselines too. If the notes overflow, add a sheet. Do not tighten the lines.
