# Journal system

`journal/templates/` holds blank, reusable forms. `journal/private/` is for the couple’s real notes and is gitignored. Do not put real names, stories, or photos from that folder into a commit or a public release build.

Sample renders may use only the fictional pair Rowan and Vale, clearly labeled.

The companion volume is a separate edition, Our Story, cross-referenced to IDs 001–108 and S01–S06. It’s a keepsake, not a scorecard.
