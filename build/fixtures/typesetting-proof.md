This page is a typesetting fixture. It is not one of the 108 experiences, not a signature session, and not a page to copy into `release/` as if a chapter had been written.

## The hook

The opening has to carry a title, a deck, and a motif without crowding the first sentence. If the motif file is on disk, it sits in that opening. If it is not, the page still has to look finished.

## Before you begin

You need a pen if you want to test the lines. You do not need a partner, a problem, or a finished chapter. This proof is about the page.

## Three cards

Pass, pause, and keep are ordinary moves. These cards are a layout sample, not a new activity.

```cards
Ask | One question, spoken once, then left alone.
Pass | A complete answer. No reason is owed.
Keep | One line on the shared page, if you want a line at all.
```

## Our Story

Private pages are optional to share. The lines below are blank on purpose. Nothing here is a memory of a real couple. The prompts are fixture copy, so the rules have something to sit under.

```journal
session: date, time, place, version played, mood if wanted, intention, initials if wanted, done or paused
partner_a:
- A prompt specific to this fixture, for one of you
- A second prompt, still for that person
partner_b:
- A prompt with equal room, not a copy that assumes the same role
- A second prompt for the other person
shared:
- What actually happened
- The line or moment worth keeping
- What we discovered
- What we might do next, if anything
revisit:
- Attempt, date, and what changed
- Then versus now
```

The lines are for a hand. If a sentence does not fit, that is a finding about the page, not about the person writing.
