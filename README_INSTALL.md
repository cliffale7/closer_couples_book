# Instructions — Phase 3 drop-in kit

This is a **completion kit for the book repository** `cliffale7/closer_couples_book`, not the Android project and not a replacement book.

1. Back up the existing repository and keep its current local changes. Extract the ZIP package; copy the **contents of the package root** into the **root of the existing book repository**, merging `.cursor/agents/` but keeping your existing agent files and source materials. Do not extract into a nested new book project.
2. Open the existing book folder in Cursor, use Agent mode and paste `CURSOR_PHASE3_LAUNCH_PROMPT.txt`. The entrypoint is `@CURSOR_PHASE3_FIRST_EDITION_COMPLETION.md`.
3. The work order requires safe branch/worktree use, specialist subagents, actual content revisions, tests, full re-exports, independent quality review and evidence-backed status. It specifically **forbids trimming or splitting** the 1,452-page edition for retail constraints.
4. New work products should be committed to your existing repository as source code/art/text plus appropriately sanitized public editions, respecting `.gitignore` for personal journals. Review a phase3 branch before merging to main.
5. When Cursor finishes, start with `release/OWNER_REVIEW_START_HERE.md` and `planning/CURRENT_RELEASE_STATUS.md`. The 13-entry field test list and art contact sheets allow you to give meaningful owner feedback before approval.
