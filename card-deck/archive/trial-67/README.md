# Trial deck

Picture-free prototype. The book is unchanged.

Read `SCAN.md` first. Under each title is the invitation copied from that chapter. Each file under `prototype/` is one card, grouped by the part it comes from. The color is the physical stack. Do not shuffle the stacks together. The first move on a card is a draft for starting. A later pass checks it against the chapter before it is treated as final.

## Template

Every card has the same face:

1. Color band, stack name, and chapter id
2. Title
3. Time, energy, and intensity
4. Invitation, taken from the chapter's deck line
5. First move, short enough to start without the book
6. The pass line

`picture: none` until the text is approved. Touch is marked on the card and only appears inside the stack where the chapter already had it.

## What this trial left out

Five from each of parts 1–12, and seven from part 13. The rest of the 108 stay in the book and can become later cards in the same color. Signature sessions S01–S06 are not in this trial.

Multi-day exercises, the twelve-hour day, and The Relationship Escape Room are out of this first test so a stack can be tried in one sitting. The escape room still needs its sealed packets and the book.

## Workflow

The selection and the template stay with one editor, so the cards do not drift.

When a stack needs a closer read against the chapter, split the writers by color, not by individual card:

- Copper, Burgundy, Teal: knowing, courage, closeness
- Rose, Plum, Amber: affection, desire, play
- Indigo, Slate: inner life and trust
- Forest, Gold: adventure and story
- Ember, Sage, Ink: curiosity, future, and the workshop

One intimacy pass reads every card marked touch, plus the whole Plum stack. One proof pass checks that every file still uses this template. Picture-making waits until the text of a stack is approved.
